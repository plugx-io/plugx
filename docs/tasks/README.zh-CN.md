# 任务卡使用说明

每张任务卡是一个 `.md` 文件，frontmatter 格式固定：

```yaml
---
id: P1-06
title: 契约检查脚本
status: 待认领        # 待认领 / 进行中 / 已完成
owner: ''             # 认领者（人或 AI 的名字）
---
```

## 正文固定四节

1. **目标** —— 为什么做
2. **范围** —— 允许新建/修改的文件清单；范围外的改动必须先回写本卡
3. **验收标准** —— 可逐条核对的清单
4. **验收命令** —— 必须真实跑通的命令

## 完工动作

- 状态改为「已完成」，owner 填自己
- 文末追加「完工记录」：日期、验证命令输出摘要、遗留问题
